# SwingChat

スマホを拍に合わせて振り、残像で文字を描くAndroidネイティブ試作です。Kotlin + Android Canvasで実装しています。WebView・加速度センサー・ネットワーク権限は使いません。

## Xperia SOG14で試す

SOG14はXperia 10 VIです。[ソニーの仕様](https://www.sony.jp/xperia/xperia/xperia10m6/spec.html)では画面は60Hzのため、この端末で120Hz描画はできません。初期値は1文字（H）・16列です。

1. APKをインストールしてSwingChatを開きます。
2. まず1文字・16列・80 BPM程度から始めます。
3. 「4拍カウントして開始」を押し、上下の別色マークに合わせて腕を前へ振ります。
4. 各拍の文字列先頭でマークが点灯します。文字の表示後は消灯するので、その間に腕を戻します。復路には文字を描きません。
5. 逆に見えたら「文字の進む方向を反転」、長さが合わなければテンポと表示時間を調整します。

文字・テンポ（40–160 BPM）・表示時間（拍の35–80%）・明るさ・色・解像度を保存します。ピンクの文字を選ぶと合図はブルーに変わります。画面下部のfpsはChoreographerのコールバック頻度の実測で、パネルの実際の発光を測定するものではありません。

画面と同じ解像度の表示モードから最大Hzを要求し、表示中は明るさを指定してスリープを防止します。終了・バック・アプリ切替時に表示を停止し、明るさとモード要求を元に戻します。OSの省電力・温度・端末設定によって希望のHzにならない場合があります。

**画面の更新上限は超えられません。** 例えば60Hz・0.3秒なら約18回、120Hzなら約36回の更新です。細かすぎる列は飛びます。腕を前に出す動きに画面の横方向の移動がほとんどない場合も、残像の文字は広がりません。画面を観客に向け、横方向にも移動させる必要があります。一定速度を仮定し、実際の位置補正は行いません。

ストラップを使い、周囲の安全を確認してください。強い点滅が苦手な方は使用を控えてください。

## APKのビルド・入手

Android Studioで `android/` を開き、JDK 17以上とAndroid SDK 35を使います。

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

生成先: `android/app/build/outputs/apk/debug/app-debug.apk`

GitHubの **Actions → Android APK → 成功した実行 → Artifacts → SwingChat-debug-apk** からもダウンロードできます（GitHubへのログインが必要です）。ZIPを展開し、中のAPKをスマホで開いてインストールします。インストール元アプリの許可を求められた場合はAndroidの案内に従ってください。これは検証用のdebug APKで、Playストア公開用ではありません。別環境で生成したdebug APKに更新する際、署名が違う場合は旧版をアンインストールする必要があります。

Android 8.0（API 26）以上。実機の残像品質・SOG14の実際の動作は未検証です。タイムラインは単調増加するナノ秒クロックに基づき、4拍カウントイン・先頭マーク・片方向表示・暗い復路・長時間の拍境界をユニットテストで検証します。

既存のGitHub Pages設定は変更しません。GitHub PagesのURLからAPKが自動的に起動するものではありません。
