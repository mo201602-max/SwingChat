# SwingChat — Android

Kotlin + Android Canvasによる残像文字表示の試作です。**角度に同期して往復表示するモード**と、比較用の一定テンポ・片方向モードを搭載しています。WebViewやネットワーク権限は使いません。

## 角度モードで試す（初期設定）

1. スマホを縦に持ち、「角度に同期（往復）」を選びます。最初は1文字（H）・16列がおすすめです。
2. 表示角度は初期値120°（中央から−60°〜＋60°）。30〜160°に調整できます。
3. 「左右に振る（スマホの縦軸）」または「前後に振る（スマホの横軸）」を選びます。
4. 振る範囲の中央の向きにスマホを向けて「中央を向けて開始」。最初の有効な回転センサーデータを中央として記録します。
5. 肘や肩を中心に、スマホの向きも変えながら弧を描いて振ります。往路と復路で同じ角度に同じ列を描き、復路で鏡文字にならないようにします。
6. 中央がずれたら、その向きに戻して画面の「ここを中央に」を押してください。左右が逆なら設定の「文字の進む方向を反転」を使います。

範囲外・静止中・センサー更新の停止中は文字を消灯します。文字列の先頭の角度では画面上下に別色マークが出ます。これは拍の合図ではなく、位置の目安です。表示中に相対角度と描画fps、使用する回転センサーの種類が確認できます。アプリ切替・終了時にはセンサーを解除して消灯し、明るさと表示モード要求を戻します。

角度モードは`TYPE_GAME_ROTATION_VECTOR`を優先し、なければ`TYPE_ROTATION_VECTOR`を使います。センサーが使えなければその旨を表示します。相対姿勢を開始時のスマホ座標の縦軸／横軸に対する回転角として求めます。100Hzを要求しますが、実際の通知頻度や精度は端末依存です。加速度の二重積分による位置推定はしません。GAMEセンサーは磁気の影響を受けにくい一方、長時間使うと向きがずれる場合があり、再中央設定が必要です。

**向きは空間の位置そのものではありません。** 同じ角度で同じ位置に来る振り方を仮定します。その場でスマホだけ回転させると光が空間に広がらず、向きを一定にして平行移動するだけでは角度を検出できません。画面を観客に向けつつ、光が観客から見て横に広がるように、ゆっくりした弧から試してください。回転によって画面が見えなくなるほど広い範囲を無理に使う必要はありません。

## Xperia SOG14と画面の制約

SOG14はXperia 10 VIです。[ソニーの仕様](https://www.sony.jp/xperia/xperia/xperia10m6/spec.html)では画面は60Hzのため、120Hz描画はできません。角度に同期しても画面の更新上限は変わりません。例えば0.3秒で通過すると約18回の更新しかなく、細かい列は飛びます。まずは16列・1文字・ゆっくりした動きで試してください。表示fpsは描画コールバックの頻度で、実際のパネル発光を測定するものではありません。

高いHzの表示モードを優先して要求しますが、省電力や温度などで制限される場合があります。ストラップを使い、周囲の安全を確保してください。強い点滅が苦手な方は使用を控えてください。

## 従来の一定テンポモード

「一定テンポ（片方向・従来方式）」にするとセンサーは使いません。4拍のカウントイン後、別色マークと文字列の先頭が各拍の開始時に点灯し、表示後は腕を戻すために消灯します。テンポ40〜160 BPM、表示時間35〜80%を調整できます。文字・表示方式・軸・角度幅・明るさ・解像度・色・方向反転とテンポ設定を保存します。

## ビルドとAPK

Android Studioで`android/`を開きます。JDK 17以上、Android SDK 35、Android 8.0（API 26）以上に対応します。

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

生成先: `android/app/build/outputs/apk/debug/app-debug.apk`

GitHubの **Actions → Android APK → 成功した実行 → Artifacts → SwingChat-debug-apk** からも入手できます（GitHubログインが必要です）。ZIPを展開してAPKをスマホで開きます。これはdebug署名の検証用APKです。異なる環境で生成したAPKは署名が異なる場合があり、その場合は旧版をアンインストールしてからインストールします（保存設定は消えます）。

相対角度・折り返し・範囲境界・再中央設定・停止／更新停止時の消灯と従来タイミングをユニットテストで検証しています。SOG14実機のセンサー挙動・残像品質は未検証です。GitHub Pagesの設定は変更しません。
